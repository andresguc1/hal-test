# Security Policy

## Supported Versions

We strongly recommend using the latest stable version of HalTest. Security updates are only provided for the latest major version.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within HalTest, please do **NOT** open a public issue.

Instead, please responsibly disclose it by emailing **[andresguc1@gmail.com]** (replace with your actual contact or security email).

We treat security reports with the highest priority and will aim to respond within 48 hours.

### What to include in your report

- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.
- Any proof of concept (PoC) code or screenshots.

Thank you for helping keep HalTest secure!
